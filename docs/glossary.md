## Formatting

- Dates: `es-MX` → `19 may 2026` (never `May 19, 2026` in Spanish).
- Money: `$` prefix with locale grouping (`es-MX` / `en-US`).
- Plurals: `1 lote` / `2 lotes`; `1 lot` / `2 lots` — never mix.
